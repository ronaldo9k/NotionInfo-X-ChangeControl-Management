    • 📋 입출고 현황 탭 (맨 처음 화면)

  • ① 푸로찜제품별 현황 : 표 1장으로 제품(12/15/20 KG) 재고를 한눈에 봅니다.
    · 현재 재고량(파란 음영) = 창고에 실제 있는 양
    · 예정 재고량(초록 음영) = 앞으로의 납품까지 반영한 양
    · 마지막 입고 = 마지막으로 창고에 들어온 날. 26-11-16 (2일)처럼 며칠 지났는지도 알려주고, 30일이 넘으면 주황색이 됩니다.
  • ② 배송 필요 List (출고 대기) : 손님에게 보내야 하는 것들. ③ 본사납품 필요 List (입고 대기) : 본사에서 받아야 하는 것들.
    · 언제 보이나요? 납품일자가 비어 있는 페이지는 전부 표시됩니다. 선입금(입금일자 있음)이어도, 납품일자를 아직 안 채웠다면 반드시 보입니다. 납품일자를 입력하면 그 때 목록에서 사라집니다. · 날짜 옆 (월)(화)(수)… : 납품요청일의 요일은 항상 한글 한 글자로 표시됩니다. (12월 등에 영문(Tue)으로 보이던 현상 수정 — 앱이 요일을 직접 계산) · 오늘이 납품요청일인 행은 거래처와 납품형태가 파란 음영으로 표시되어 한눈에 구분됩니다. · 납품일자 칸을 눌러 달력에서 날짜를 고르면 저장 버튼 없이 바로 노션에 저장됩니다. (저장 중 주황 테두리 → 성공하면 초록 테두리)
  • ④ 최근 납품 List : 최근 7일 동안의 납품 기록입니다.
  • 수정 / 삭제 버튼 : 각 행마다 있습니다.
    · 수정(파란 버튼) : 그 행의 모든 정보를 고칠 수 있어요. 고친 뒤 "저장 및 이력 기록"을 누르면 됩니다. · 삭제(빨간 버튼) : 그 행의 정보를 노션에서 지웁니다. ①비밀번호 입력 → ②"정말 삭제할까요?" Yes 선택이라는 2단계 확인이 있어서 실수로 눌러도 안 지워집니다. 지운 페이지는 노션 휴지통에 남아 복구할 수 있고, 삭제 기록도 변경 이력에 남습니다.

    • 📊 총판 통계 탭

  • 모든 통계는 납품일자가 있는 기록만, 그 날짜 기준으로 계산합니다.
  • 총 미수금 : 상태에 "미수"가 있는 건들의 판매금 합계.
  • 올해 평균 Profit : 올해 출고 Profit을 전부 더한 값 ÷ 지금까지 지난 달 수. (예: 10월이면 ÷10) 소수점은 버립니다.
  • 올해 총 입금액 : 올해 받은 돈(Σ입고액)의 총합.
  • 작년 실적 3개 카드 : ① 입고량/입고액 ② 출고량/판매금 ③ Profit — 각각 총합과 12으로 나눈 월 평균이 같이 나옵니다.
  • 택배비 카드 : 당월·전월·올해 총 택배비와, 그 택배비 계산에 쓰인 수량 총합이 같이 나옵니다.
  • 월별 3개월 블록 : 1~3월 / 4~6월 / 7~9월 / 10~12월, 4개의 블록으로 나뉘고 각 블록은 구분-월-월-월 맨윗줄 + 판매수량 → 판매금 → Profit → 입고수량 → 입고액 5줄, 총 6줄로 구성됩니다. 판매금·입고액 숫자도 다른 줄과 같은 크기이며, 블록 가로폭은 다른 카드 행과 같고 모바일에서는 세로로 쌓여 한 화면에 다 보입니다. (연도는 올해년도 자동 표시 — 내년이 되면 27년으로 바뀝니다)
  • 기간 검색 : 시작일~종료일을 고르고 "조회"를 누르면 그 기간 동안의 실적 합계가 나옵니다.

    • 🏪 거래처 관리 / 거래처 추가 탭

  • 거래처 관리 : 거래처 목록을 검색하고 수정(정보 변경)·보관(노션 휴지통 이동)을 할 수 있습니다.
  • 주소 칸의 다음 주소 검색 버튼으로 도로명·지번주소를 한 번에 넣을 수 있어요.
  • 수정 창의 순서 편집 : 속성을 끌어다 놓거나 ▲▼ 로 순서를 바꿀 수 있어요. 기본 순서로를 누르면 처음 배치로 돌아갑니다.
  • 거래처 추가 : 새 거래처를 만들거나, 오래 쓰지 않은 휴면 거래처를 재사용할 수 있습니다. (출고 기록이 0건인 거래처만, 저장할 때 서버가 다시 확인합니다)

  • 누가·언제·무엇을 바꿨는지 전부 기록됩니다. 검색과 필터로 찾을 수 있어요.

    • 🔎 입출고 검색 탭

  • 거래처 검색 : 글자를 일부만 입력해도(예: "프렌" → "프렌즈푸드코리아") 이름에 들어 있는 거래처가 바로 보이고, 후보를 누르면 검색칸에 정확히 선택됩니다. 검색칸을 누르면 가나다순 전체 거래처 목록에서 고를 수도 있습니다.
  • 기간 바로가기 : 이번달 / 두달 / 올해 버튼 또는 시작일~종료일 캘린더로 기간을 지정합니다. (납품일자 기준, 납품일자가 없으면 주문일자)
  • 검색 결과 2개 표 :
    · 출고 표(입출고="출고" 또는 출고여부 체크) : No.·거래처·수량·최종입금액·납품일자·입금일자·상태·구분(규격)·납품형태·택배비·명세표발송여부·제2배송지·박스히어로완료·집계월·발행완료 — 맨 아래 줄에 수량·최종입금액·택배비 총합과 박스히어로완료·발행완료 미체크 개수(다 체크면 0)가 나옵니다. · 입고 표(입출고="입고" 또는 출고여부 미체크) : No.·거래처·수량·입고액·납품일자·입금일자·상태·구분(규격)·납품형태·발주서발송여부·발주관리번호·제2배송지·박스히어로완료 — 맨 아래 줄에 수량·입고액 총합과 박스히어로완료 미체크 개수가 나옵니다.
