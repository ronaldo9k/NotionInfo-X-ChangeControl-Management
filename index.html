사용 매뉴얼 (v3.0)

초등학생도 이해할 수 있는 사용법

1. 이 앱이 하는 일

  • 노션에 있는 거래처 DB / 입출고 DB / 제품 DB를 휴대폰·PC에서 바로 보고 고치는 도구입니다.
  • 모든 변경은 Google 시트 "변경 이력 Log"에 언제·누가·무엇을·무엇에서 무엇으로 바꿨는지 자동 기록됩니다.

    • 2. 입출고 현황 탭

  • ① 제품별 현황: 제품마다 창고 재고량 · 납품예정 반영 재고량 · 그리고 "마지막 입고일 : 26-11-02 (16일 경과)" 처럼 한 줄로 표시됩니다. (이전에는 두 줄이었습니다)
  • ② 배송 필요 List (출고 대기): 입출고 값이 "출고" 이면서 배송필요 값이 비어있지 않은 건만 나옵니다. 컬럼은 No. / 거래처 / 납품형태 / 납품요청일 / 납품일자 / 주소 / 명세표발행 / 발송대기 입니다.
  • ③ 본사납품 필요 List (입고 대기): 입출고 값이 "입고" 이면서 배송필요 값이 비어있지 않은 건만 나옵니다. 컬럼은 No. / 거래처 / 납품형태 / 납품요청일 / 납품일자 / 발주서발송 / 발주서 번호 입니다.
  • ④ 최근 납품 List (최근 7일): 컬럼은 No. / 입출고 / 거래처 / 납품일자 / 입금일자 / 상태 / 박스히어로 / 택배비 / 명세표 발송 입니다. (입출고·입금일자 컬럼이 새로 추가되었습니다)
  • 납품일자 입력 방법: 리스트의 납품일자 칸을 누르면 휴대폰·PC 달력이 뜹니다. 날짜를 고르면 곧바로 노션 "납품일자"에 저장되고(저장 버튼 없음) 변경 이력에도 자동 기록됩니다. 저장 중에는 칸 테두리가 주황색, 성공하면 초록색이 됩니다. 실패하면 원래 값으로 되돌아가고 경고창이 뜹니다.
  • 각 행의 수정 버튼을 누르면 그 페이지의 모든 속성을 고칠 수 있습니다.

    • 3. 총판 통계 탭

  • 모든 통계는 납품일자가 있는 페이지만, 그 납품일자 날짜 기준으로 계산합니다. (예전처럼 "납품일자 없으면 주문일자"로 섞지 않습니다)
  • 총 미수금 = 노션 "상태" 값이 미수확인인 페이지들의 판매금 합계입니다. (예전의 "판매금 − 입금액" 뺄셈 방식은 폐기했습니다)
  • 올해 평균 Profit = 올해 납품일자 기준 Profit 합계 ÷ 올해 납품일자가 있는 페이지 수. 작년 평균 Profit도 같은 방식으로 작년 것만 계산합니다.
  • 올해 평균 출고수량 = 올해 출고량 합계 ÷ 당월 숫자(예: 11월이면 ÷11). 평균 입고수량도 동일합니다.
  • 월별 카드(판매수량·입고수량·Profit·판매금·입고액)는 "26년 1월~12월"처럼 올해 연도가 자동으로 붙습니다.
  • 아래 기간 검색은 납품일자 기준으로 그 기간의 합계·미수금·평균 Profit을 보여줍니다.

    • 4. 거래처 관리 / 거래처 추가

  • 목록에서 수정을 누르고 값을 바꾼 뒤 저장 및 이력 기록 → 예/아니오 확인 → "예"를 눌러야 저장됩니다.
  • 주소 입력란의 다음 주소 검색으로 도로명·지번주소를 한 번에 넣습니다.

    • 5. 변경 이력 탭

  • 모든 기록을 검색할 수 있고, 보관(삭제)한 페이지는 복원 버튼으로 되살립니다.
  • 하단 Google 시트 원본 열기로 전체 Log를 볼 수 있습니다.

    • 6. 이번 버전에서 달라진 점 (v2.0 → v3.0)

  • 상단의 "Notion 독립 관리 시스템 v2.0 · 변경 이력 자동 누적" 문구와, 입출고 현황 상단의 긴 설명 문구를 삭제해 화면을 넓게 썼습니다.
  • 상단 상태 표시는 실제 연결 점검 결과로 "연결됨" 또는 "연결 끊김" 으로만 표시됩니다. 매뉴얼 버튼의 아이콘을 없애 휴대폰에서도 한 줄에 들어갑니다.
  • 하단 탭 5개가 휴대폰에서 한 줄에 3개씩(2줄) 배치됩니다.

    • 7. 주의

  • 주소를 아는 사람은 누구나 열 수 있는 앱입니다. 필요한 사람에게만 공유하세요.
  • 수식·롤업(자동 계산) 값은 노션에서 계산되므로 이 앱에서는 바꿀 수 없습니다.
